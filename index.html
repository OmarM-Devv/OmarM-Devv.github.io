Application Tracker Agent

A personal automation tool that helps reconcile job-application activity from Gmail with a private Google Sheets tracker.

What it does

The agent reads relevant Gmail messages in read-only mode, identifies application updates, and compares them with the user's job-application tracker.

Google Sheets

The agent reads and, when explicitly authorised by the user, updates specific Google Sheets used for application tracking.

Private use

This application is intended for the owner's personal use. It is not a public SaaS product and does not sell or monetise Google user data.

Google API access

The application requests only the access it needs:

  • gmail.readonly to read relevant Gmail messages.
  • spreadsheets to read and update the user's application-tracking sheets.

Authentication credentials and refresh tokens are not collected through this website. They are stored by the user in their own local environment or private GitHub Actions secrets.
