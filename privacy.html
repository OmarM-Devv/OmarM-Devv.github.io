Privacy Policy

Last updated: 22 September 2026

1. Purpose

Application Tracker Agent is a personal-use tool that helps the owner reconcile job-application activity with a private Google Sheets tracker.

2. Google data accessed

The application may access:

  • Gmail messages and message metadata through the read-only Gmail scope https://www.googleapis.com/auth/gmail.readonly.
  • Google Sheets data through https://www.googleapis.com/auth/spreadsheets.
  • Google Drive file names and modified dates, never file contents, through the read-only metadata scope https://www.googleapis.com/auth/drive.metadata.readonly.

3. How Google data is used

Gmail data is used only to identify and reconcile job-application events such as acknowledgements, interview invitations, rejections, recruiter replies and related application updates.

Google Sheets data is used only to read the owner's tracker and, when the owner deliberately enables write mode, update relevant tracker fields.

Google Drive metadata is used only to list the names and modified dates of the folders inside one folder of tailored CVs chosen by the owner, so the agent can point out a CV that has no matching tracker entry. File contents are never read.

4. Data storage

This website does not collect or store Gmail messages, Google Sheets content, OAuth refresh tokens or Google account passwords.

OAuth credentials and refresh tokens used by the agent are controlled by the owner and are stored in the owner's local environment or in private GitHub Actions secrets.

5. Data sharing and sale

Google user data is not sold, rented or used for advertising. The application does not share Google user data with third parties except where required for the technical operation of services chosen and controlled by the owner, such as Google APIs and GitHub Actions.

6. Limited use

Application Tracker Agent's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Use of information received from Google APIs is limited to the functionality described on this website and is not used for unrelated purposes.

7. Data retention

The application does not maintain a separate commercial database of Google user data. Any information written to the owner's Google Sheets remains under the owner's control.

8. Revoking access

The owner can revoke the application's Google account access at any time through their Google Account security settings. Local tokens and GitHub Actions secrets can also be deleted by the owner at any time.
